## Цель работы
Изучение и практическое применение циклических конструкций с предусловием (while) и постусловием (do-while).

## Описание задачи
Программа производит расчет работы изотермического (A1) и адиабатического (A2) расширения 1 кмоля идеального газа при переходе из начального объема V1 в конечный объем V2. Вычисления выполняются по формулам:

1) Изотермическое расширение:
   A1 = R * T * ln(V2 / V1)

2) Адиабатическое расширение:
   A2 = (R * T / (n - 1)) * (1 - (V1 / V2)^(n - 1))

## Исходные данные
Газовая постоянная (R): 8.31 кДж/(кмоль·град)
Температура процесса (T): 320 К
Показатель адиабаты (n): 1.2
Начальный объем (V1): 2 м^3
Конечные объемы (V2): 2.2; 2.4; 2.6; 2.8; 3; 4; 5; 6; 7 м^3
